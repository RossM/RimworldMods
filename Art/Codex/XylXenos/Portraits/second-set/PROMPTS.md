# Second portrait set - design revisions

These are alternatives for comparison with the established portraits, based on the author's criticism. Generated with the built-in imagegen tool. The source images and first README table remain unchanged. Clothing, accessories and individual history are artistic interpretations rather than new mod canon.

## Prompt development

Three passes were used before generation: diagnose the visual signal, choose a change that preserves character, then constrain anatomy and rendering. The main principle is to alter the cause of each reading instead of adding generic damage or making everyone unhappy. The author clarified before generation that Succuboids visually stop aging at 18; her prompt preserves that youthful adult appearance.
